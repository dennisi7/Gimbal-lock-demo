The maths behind the flight

This demonstration uses active, intrinsic Z–Y–X rotations: R = Rz(yaw) Ry(pitch) Rx(roll). At pitch +90°, the instantaneous roll axis points opposite the yaw axis. Roll and yaw changes become redundant; the spacecraft itself still has all its physical rotational freedom. At that configuration, increasing roll and yaw by the same angle leaves the orientation unchanged.

The quaternion chapter starts at the same orientation and applies rotations about independent fixed world axes using q ← Δq · q, normalizing after each update. It changes both the representation and the input method. Merely converting the same Euler sliders into quaternions would retain their singularity. Quaternions do not repair a physical gimbal mechanism.

SLERP uses normalized quaternions with a sign correction to select a shortest path. Its parameter changes linearly in time. The scene is an illustrative spacecraft, not an aerospace flight simulation. Euler singularities · Quaternion operations
